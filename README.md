# Flawseekr — a minimalist, modern, techie Jekyll theme

A dark-first Jekyll theme for a small writing collective. Home / Who We Are /
Blog / Contact, plus per-author, per-category and per-tag archives and a
client-side search.

## Features

- **Minimalist / modern / techie** design — dark-first with a light toggle
  (persisted, no flash), Inter + JetBrains Mono, a subtle grid backdrop.
- **Pages**: `/` landing (Welcome · What We Do · Team), `/about/`,
  `/blog/`, `/contact/`, `/search/`.
- **Blog** posts as a Jekyll collection → `/blog/:title/`.
- **Archives** generated by a plugin:
  - `/@:username` — author bio + their articles
  - `/category/:category`
  - `/tag/:tag`
- **Search** — client-side over a generated `search.json` (works everywhere,
  including GitHub Pages). The search bar appears only on `/blog/` and
  deep-links to `/search/`.
- **SEO** — `jekyll-seo-tag`, `jekyll-sitemap`, `jekyll-feed`, canonical URLs,
  Open Graph & Twitter cards, JSON-LD.
- **Accessible** — skip link, focus styles, reduced-motion support, semantic
  landmarks.

## Project layout

```
_config.yml            # site config + nav + collections
_plugins/
  archive_generator.rb # builds /@user, /category, /tag pages
_layouts/              # default, home, page, article, author, category, tag
_includes/             # head, header, footer, cards, search-bar
_sass/                 # design tokens + components (see main.scss)
assets/css/main.scss   # imports the _sass partials
assets/js/             # theme.js (toggle), search.js
_data/                 # authors.yml, team.yml, services.yml
_blog/                 # your posts (Markdown)
index.html about.md blog.html contact.md search.md
```

## Run locally

```bash
bundle install
bundle exec jekyll serve --livereload
# → http://localhost:4000
```

## Deploy

The author/category/tag pages come from a custom plugin, and **GitHub Pages'
built-in build ignores `_plugins/`**. Two options:

1. **GitHub Actions** (recommended) — `.github/workflows/deploy.yml` runs a
   full `jekyll build` and deploys to Pages. Just push to `main` and set
   Pages → Build and deployment → Source = GitHub Actions.
2. **Any static host** (Netlify, Cloudflare Pages, S3) — build with
   `bundle exec jekyll build` and upload `_site/`.

## Add an article

Create `_blog/my-post.md`:

```yaml
---
title: "My post title"
date: 2026-07-22
author: xchopath        # must match a key in _data/authors.yml
category: Security        # one category → /category/security/
tags: [c, fuzzing]        # many tags → /tag/c/, /tag/fuzzing/
read_time: 7
description: "One-line summary used in cards, search and SEO."
---

Your Markdown here.
```

Any image embedded in the post body should carry explicit dimensions and
`loading="lazy"` — kramdown renders plain `![]()` Markdown images with
neither, which risks layout shift and un-lazy-loaded downloads on every
post. Use a raw `<img>` tag instead:

```html
<img src="{{ '/assets/uploads/2026/01/diagram.webp' | relative_url }}"
     alt="…" width="1536" height="1024" loading="lazy">
```

## Customize

- **Site name, URL, social, nav** → `_config.yml`.
- **Colors, fonts, spacing** → `_sass/_variables.scss` (design tokens).
- **Team / authors / services copy** → `_data/*.yml`.
- **Contact form** → set your Formspree endpoint in `contact.md`.
